# Test datasets: sources and licenses

These files are redistributed only so that the regression suite (`collaudi/`) is reproducible.
They are **not** covered by the MIT license of this repository: each belongs to its authors and keeps
its original license. Some files are lightly prepared versions (filters, joins, added columns) of the
original data. If you are a rights holder and want a file removed, please open an issue.
